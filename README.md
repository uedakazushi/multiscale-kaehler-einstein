- 主原稿：`papers/multiscale-kaehler-einstein.tex`（Part I）
- 独立論文：`papers/secondary-periods-torelli.tex`（Part II）、`papers/conifold-localization.tex`（Part III）
- 正本：`main`。研究全体の入口は [research-hub](https://github.com/uedakazushi/research-hub)。

Part IIIのglobal pGH収束は無条件の定理ではなく、wall-compatible liftingを仮定した条件付き結果と、actual metricについての予想を区別する。ファイル配置・組版状況・移行の制約は [研究方針](00_research_plan.md) に記す。
